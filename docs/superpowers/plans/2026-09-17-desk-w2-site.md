# Phase W2: the site as a desk — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn one scrolling page into a navigated desk — Desk, Risk, Execution, Argument and Ops — each its own route and its own embedded page, with Figure 1 gaining the order and fill bands A2 made real.

**Architecture:** Nothing is fetched at runtime and nothing is generated at runtime. Every page is a string module written by a rule in `lib/dune` that concatenates files out of `web/`, served from `lib/server.ml`'s one `routes` table. W2 adds a shared shell — header, banners, nav — a shared client — the formatters, the frame bookkeeping, one `EventSource` — and three new bodies with their own renderers. The client's hard rule is that every page is missing most elements, so every lookup returns early rather than throwing.

**Tech Stack:** OCaml 5.2.1, dune 3.16 (`rule`/`with-stdout-to`/`cat`), hand-written HTML/CSS/ES5-compatible JavaScript with no libraries and no build step, alcotest, `node --check`.

**Spec:** `docs/superpowers/specs/2026-09-12-the-desk-design.md` — §4 (Track W) and §5's phase table row for W2. §3.13 says what A4 owns.

**This plan was reviewed twice before execution** and rewritten against both: `.superpowers/sdd/2026-09-17-desk-w2-site/plan-review.md` and `plan-review-2.md`. The first review's seven Critical findings are why the shell holds the masthead and not only the nav. The second review's are why **Task 2 is a contract rather than a line-by-line cut**: four attempts to name the exact lines to move were wrong in four different ways, because `dashboard.js`'s module state is read on both sides of every boundary one could draw from the outside. The cut is made by the implementer, against the compiler and the browser, and reported.

## Global Constraints

- **One binary, no external assets.** Every byte a page needs is embedded at build time. No CDN, no font file, no image file, no runtime template.
- **The delimiters.** Page sources are concatenated into `{ohcamel_html|...|ohcamel_html}` and the JSON pin into `{ohcamel_json|...|ohcamel_json}`. After every task: `grep -rF '|ohcamel_html}' web/` and `grep -rF '|ohcamel_json}' web/` print nothing.
- **The kernel may not name the desk.** `grep -rE 'paper-api\.alpaca\.markets|/v2/orders|Sqlite3|ohcamel_desk' lib/` prints nothing, comments included. The desk's routes are registered as extensions from `desk/`.
- **Every element lookup returns early.** A script catted into five pages runs on pages that contain none of its elements. `var t = document.getElementById("x"); if (!t) return;` is the shape; a function that assumes its element exists is a broken page, not a broken section.
- **Text only, never HTML.** Server-supplied strings (limit names, order reasons, rule failures, scenario descriptions, venue text, error sentences) reach the DOM through `textContent` or a created text node. `innerHTML` may carry only a fixed literal with no interpolation.
- **The formatters are `window.OhCamelFormat = { money, pct, el }`.** There is no `dollars`. `money(null)` returns `null`, so a caller prints a dash for it.
- **Every mutating request keeps its header.** `X-OhCamel-Desk: 1` on orders, cancel, kill and kill/reset; mutating controls appear only where the frame's `tickets` says tickets are accepted; a reset keeps its deliberate confirmation. W2 moves this code between files and may not weaken it.
- **Unknown is unknown.** A figure the process does not know prints as a dash, never `0`. A count the process does know, such as zero open orders, prints as zero.
- **Both colour schemes.** Every new rule is defined for light and for `@media (prefers-color-scheme: dark)`. `page.css` is shared by every page, byte for byte.
- **The route list is asserted three ways.** `lib/server.ml`'s `routes` table generates the dispatcher and the 404 listing; `test_server.ml` pins that listing; `deploy/smoke.sh`'s `EXPECTED_ROUTES` carries the same list in the same order. A task that adds a route updates all three **in its own commit**, never in a later one.
- **`deploy/smoke.sh` takes a base URL as its first bare argument** and then only `--live`, `--sse-window` and `--expect-sha`. There is no `--local`; an unknown flag exits 2.
- **Counts.** The main suite is 440 at the start of this phase (`lib/verified.ml`'s `tests`), the scheduler suite 7. Each task states its count, updates `lib/verified.ml`, and updates the three sentences that print it: `README.md`'s "`make test` runs N tests", `docs/overview.md`'s "**N tests**", `docs/status.md`'s "**N hermetic tests**". Coverage is re-measured once, by the controller, after the whole-branch review.
- **Every new test case is registered** in its file's suite list. A case that is written and not registered is a case that never runs.
- **`dune build @fmt` stays clean** for OCaml. The generated page modules are build artefacts and are outside fmt.
- **Commit hygiene.** Stage by name; never `git add -A` or `git add .`. Never commit `notes.txt`, `claudecodehandoff.md`, `Competitive Market Behavior LLMs.pdf`, `book.sexp`, `.playwright-mcp/`, `_coverage/` or any `.env`. Every commit message ends with a blank line and exactly `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>`.

```javascript
/* The shell: which page am I. Nothing else belongs here -- a file catted into
   every page costs every page, so it stays six lines.

   The comparison is exact on pathname, so "/" is current only on "/" and not
   on every page the way a prefix test would make it. */
function markCurrentNavLink() {
  var here = window.location.pathname;
  var links = document.querySelectorAll("nav.sitenav a");
  for (var i = 0; i < links.length; i++) {
    if (links[i].getAttribute("href") === here) links[i].setAttribute("aria-current", "page");
  }
}
markCurrentNavLink();
```

**The contract.**

`window.OhCamelShared` — the frame state every section shares:
- `beginFrame(s)` — called by the stream before it fans out. Recomputes, from this frame: the symbols with no recent print, the sectors holding one, and the downstream closure of every stale cell. It calls `window.OhCamelGraph.closure` when that exists and the topology has arrived, and leaves the closure empty when it does not, which is what a page with no topology yet should show.
- `endFrame()` — called after fan-out; this is what clears the first-frame flag, so nothing is marked as moved on load.
- `value(key, text, extraClass)` and `riskCell(tr, key, share, ratio)` — the change-mark helpers, moved with the `prev` map and the flag they close over. Their calls to the local `el` become `OhCamelFormat.el`.
- `staleSymbol(sym)`, `staleSector(sec)`, `staleNode(name)` — what the moved renderers ask instead of reading a module-level set they no longer share a file with.

`window.OhCamelStream` — the connection and the page furniture:
- `onFrame(fn)`, `onSnapshot(fn)`, `onOps(fn)` — registries. Each `fn` runs inside `try`/`catch`: one broken section is a broken section, not a dead page.
- `mode()` — `"demo"` or `"live"`, from `/api/ops`, or `null` before it answers. It does not come from the frame.
- `start()` — called once, as the last statement of the last script on the page.
- It owns **every** field in `web/header.html`: `#mode`, `#feed`, `#lastprint`, `#lastframe`, `#ran`, `#nsym`, `#ks`, `#asof`, and the `#halt` and `#warn` banners. A field with no writer is a dash that never changes, which is worse than no field.
- It keeps the `/api/graph` fetch that the closure needs and hands the topology to `OhCamelShared`.

**What must still be true afterwards:**
1. `/` renders exactly as it did: positions and sectors still mark stale rows, the ledger still dims, the figure still dims, the trail still draws, the desk panel still previews and places.
2. `/ops` still opens **one** connection — its own, in `ops.js`. This task does not cat `stream.js` into that page and does not touch `ops.js`.
3. Nothing reads a variable that moved out from under it. The files are not in strict mode by accident: check each for `"use strict"` and fix what the compiler cannot catch by reading.
4. Every element lookup in `shared.js` and `stream.js` returns early when the element is absent.
5. `onSnapshot` either has a producer or is not in the API. There is no `/api/snapshot` fetch in `dashboard.js` to move — the stream delivers the same object every frame — so unless the implementer adds one, drop `onSnapshot` and let pages use `onFrame`.

   Every string that came from the process -- a limit's name from book.sexp, a
   scenario's description from stress.ml, a breach's own sentence -- is written
   with textContent. */
(function () {
  "use strict";
  var F = window.OhCamelFormat, S = window.OhCamelShared;

  function cell(row, text, cls) {
    var td = document.createElement("td");
    td.textContent = text === null || text === undefined || text === "" ? "—" : String(text);
    if (cls) td.className = cls;
    row.appendChild(td);
    return td;
  }

  function head(table, names) {
    var tr = document.createElement("tr");
    names.forEach(function (n) {
      var th = document.createElement("th");
      th.textContent = n;
      tr.appendChild(th);
    });
    table.appendChild(tr);
  }

  function renderLedger(s) { /* dashboard.js:315-358, with el/pct/money/staleNodes
                                pointed at their shared homes and #ledger as its
                                element */ }

  /* The factor the process was started with, and the book's beta to it. A beta
     the process has not estimated is a dash: a book with too little history has
     no beta, and printing 0.000 would read as "uncorrelated". */
  function renderFactor(s) {
    var t = document.getElementById("factor");
    if (!t) return;
    t.textContent = "";
    var b = s.portfolio_beta;
    [["series", s.factor], ["portfolio beta", b === null || b === undefined ? null : Number(b).toFixed(3)]]
      .forEach(function (r) {
        var tr = document.createElement("tr");
        cell(tr, r[0], "lbl");
        cell(tr, r[1], "v num");
        t.appendChild(tr);
      });
  }

  /* Gamma and vega. Zero is a real answer here -- a book with no options has no
     convexity -- so these print 0.00 rather than a dash. */
  function renderGreeks(s) {
    var t = document.getElementById("greeks");
    if (!t) return;
    t.textContent = "";
    [["portfolio gamma", s.portfolio_gamma], ["portfolio vega", s.portfolio_vega]]
      .forEach(function (r) {
        var tr = document.createElement("tr");
        cell(tr, r[0], "lbl");
        cell(tr, r[1] === null || r[1] === undefined ? null : Number(r[1]).toFixed(2), "v num");
        t.appendChild(tr);
      });
  }

  var running = false;

  function renderStress(d) {
    var box = document.getElementById("stress");
    var note = document.getElementById("stressnote");
    if (!box) return;
    box.textContent = "";
    var table = document.createElement("table");
    head(table, ["scenario", "P&L", "of equity", "equity after", "drawdown after", "new breaches"]);
    (d.scenarios || []).forEach(function (sc) {
      var tr = document.createElement("tr");
      cell(tr, sc.name, "lbl");
      cell(tr, F.money(sc.pnl), "num");
      cell(tr, F.pct(sc.pnl_fraction), "num");
      cell(tr, F.money(sc.equity_after), "num");
      cell(tr, F.pct(sc.drawdown_after), "num");
      var names = (sc.new_breaches || []).map(function (b) { return b.name; });
      cell(tr, names.length === 0 ? "—" : names.join(", "), names.length ? "over" : "");
      if (sc.description) tr.title = sc.description;
      table.appendChild(tr);
    });
    box.appendChild(table);
    if (note) {
      note.textContent =
        "As of " + (d.as_of || "—") + ". Every scenario runs on a fork of this book, so the " +
        "numbers are this book's and not an average book's, and the live graph is untouched.";
    }
  }

  function runStress() {
    if (running) return;
    running = true;
    var button = document.getElementById("stressrun");
    var note = document.getElementById("stressnote");
    if (button) button.disabled = true;
    if (note) note.textContent = "running the suite on a fork…";
    fetch("/api/stress", { headers: { Accept: "application/json" } })
      .then(function (r) {
        if (!r.ok) throw new Error("status " + r.status);
        return r.json();
      })
      .then(renderStress)
      .catch(function (e) {
        if (note) note.textContent = "the suite did not answer: " + e.message;
      })
      .then(function () {
        running = false;
        if (button) button.disabled = false;
      });
  }

  if (window.OhCamelStream) {
    OhCamelStream.onFrame(function (s) {
      renderLedger(s);
      renderFactor(s);
      renderGreeks(s);
    });
  }
  var run = document.getElementById("stressrun");
  if (run) run.addEventListener("click", runStress);
})();
