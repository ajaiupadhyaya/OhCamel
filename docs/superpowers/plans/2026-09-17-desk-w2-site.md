# Phase W2: the site as a desk — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the single scrolling page into a navigated desk — Desk, Risk, Execution, Argument and Ops — each its own route and its own embedded page, with Figure 1 gaining the order and fill bands A2 made real.

**Architecture:** Nothing is fetched at runtime and nothing is generated at runtime. Every page is a string module written by a rule in `lib/dune` that concatenates files out of `web/`, served from `lib/server.ml`'s one `routes` table. W2 adds one shared nav partial, one small shell script, three new body files with their own scripts, and splits `web/dashboard.js` into the stream it all shares and the per-page renderers. The split is mechanical: markup moves by whole section, byte for byte, and each page loads only the scripts its own sections need.

**Tech Stack:** OCaml 5.2.1, dune 3.16 (`rule`/`with-stdout-to`/`cat`), hand-written HTML/CSS/ES2015 with no libraries and no build step, alcotest, `node --check` for syntax.

**Spec:** `docs/superpowers/specs/2026-09-12-the-desk-design.md` — §4 (Track W), and §5's phase table row for W2. Read §4's last paragraph, which is the page list this plan implements, and item 9, which is the Figure 1 band.

## Global Constraints

- **One binary, no external assets.** Every byte a page needs is embedded at build time. No CDN, no font file, no image file, no runtime template. A page that fetches an asset is a defect.
- **The delimiters.** Page sources are concatenated into `{ohcamel_html|...|ohcamel_html}`; the JSON pin into `{ohcamel_json|...|ohcamel_json}`. A closing delimiter inside any file under `web/` ends the literal early and breaks the build inside a generated file. CI greps for them, and so must every task: `grep -rF '|ohcamel_html}' web/` and `grep -rF '|ohcamel_json}' web/` must print nothing.
- **The kernel may not name the desk.** CI greps `lib/` and refuses `ohcamel_desk`, `Sqlite3`, `paper-api.alpaca.markets` and `/v2/orders`, comments included: `grep -rE 'paper-api\.alpaca\.markets|/v2/orders|Sqlite3|ohcamel_desk' lib/` must print nothing. The desk's own routes are registered as extensions from `desk/`, never listed in `lib/server.ml`.
- **Text only, never HTML.** Server-supplied strings (limit names, order reasons, rule failures, scenario descriptions, error sentences) reach the DOM through `textContent` or a created text node. `innerHTML` may carry only a fixed literal with no interpolation. This is a public page.
- **Every mutating request keeps its header.** `X-OhCamel-Desk: 1` on orders, cancel, kill and kill/reset; mutating controls appear only where the frame's `tickets` says tickets are accepted; a reset still needs its deliberate confirmation. W2 moves this code between files and may not weaken it.
- **Unknown is unknown.** A figure the process does not know prints as a dash, never `0`.
- **Both colour schemes.** Every new rule is defined for light and for `@media (prefers-color-scheme: dark)`. `page.css` is shared by every page, byte for byte.
- **The route list is asserted three ways.** `lib/server.ml`'s `routes` table generates the dispatcher and the 404 listing; `test_server.ml` pins that listing; `deploy/smoke.sh`'s `EXPECTED_ROUTES` carries the same list in the same order and fails until it is updated in the same commit. Adding a page means all three.
- **Counts.** The main suite is 440 at the start of this phase (`lib/verified.ml`'s `tests`), the scheduler suite 7 (`scheduler_tests`). Each task states its own count and updates `lib/verified.ml` in the same commit. Re-measure coverage and re-date only at the end of the phase, in the controller's own commit.
- **`dune build @fmt` stays clean** for OCaml. The generated page modules are build artefacts and are outside fmt; `web/` is hand-formatted and is not fmt's business.
- **No wall clock in a test.** A test that needs time uses a `Time_source` it advances.
- **Commit hygiene.** Stage by name; never `git add -A` or `git add .`. Never commit `notes.txt`, `claudecodehandoff.md`, `Competitive Market Behavior LLMs.pdf`, `book.sexp`, `.playwright-mcp/`, `_coverage/` or any `.env`. Every commit message ends with a blank line and exactly `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>`.

`web/shell.js` — the only thing every page shares besides the sheet.

```javascript
/* The shell: which page am I. Nothing else belongs here -- a file catted into
   every page is a file that costs every page, so it stays six lines.

   The comparison is exact on pathname. "/" matches only "/", so the Desk link
   is not current on every page the way a prefix test would make it. A path the
   nav does not list (there is none today) simply marks nothing, which is the
   honest answer. */
function markCurrentNavLink() {
  var here = window.location.pathname;
  var links = document.querySelectorAll("nav.sitenav a");
  for (var i = 0; i < links.length; i++) {
    if (links[i].getAttribute("href") === here) links[i].setAttribute("aria-current", "page");
  }
}
markCurrentNavLink();
```

```javascript
/* The stream, and the parts of every page that are the same page: the header's
   live fields, the halt and warn banners, and the one EventSource.

   Every page loads this file and subscribes to it. The alternative -- each page
   opening its own EventSource -- would mean two connections from one browser on
   any page that showed two things, and the server's subscriber count, which the
   ops page prints, would stop meaning what it says.

   A renderer must tolerate a page that does not contain its elements: this file
   is catted into pages that have none of them, and a null lookup that throws
   takes the header down with it. Every accessor here returns early on a missing
   element, and so must every subscriber. */
var OhCamelStream = (function () {
  /* ... the moved code, unchanged in behaviour ... */
  var frameSubscribers = [];
  var snapshotSubscribers = [];
  var currentMode = null;

  function onFrame(fn) { frameSubscribers.push(fn); }
  function onSnapshot(fn) { snapshotSubscribers.push(fn); }
  function mode() { return currentMode; }

  /* A subscriber that throws must not stop the header, the banners or the other
     subscribers: one broken section is a broken section, not a dead page. The
     error goes to the console, which is where a reader looking for it will be. */
  function fanout(subscribers, value) {
    for (var i = 0; i < subscribers.length; i++) {
      try { subscribers[i](value); } catch (e) { console.error(e); }
    }
  }

  function start() { /* ... the moved EventSource and snapshot fetch ... */ }

  return { onFrame: onFrame, onSnapshot: onSnapshot, mode: mode, start: start };
})();
```
